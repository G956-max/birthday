# Interactive Birthday Surprise Website 🎂❤️

A premium, emotional, romantic-style interactive birthday surprise website built with React, Vite, Tailwind CSS, Framer Motion, and Lucide React.

## ✨ Features & Journey

1. **Screen 1: Welcome Greeting**
   - Displays *"Hi Beautiful ❤️"* with an animated pulsing 3D glowing heart.
   - Interactive button *"A Little Surprise For You"* with glowing effects and romantic transition.
   
2. **Screen 2: Flower Animation & Falling Petals**
   - Delicate animated flowers and rose petals drifting downwards.
   - Interactive falling petals that sparkle when tapped.
   - Romantic message reveal: *"Something special is waiting for you... ✨"*

3. **Screen 3: Birthday Introduction**
   - Cinematic blur-to-focus text reveal: *"Happy Birthday!"*
   - Birthday girl's name adorned with gold and rose radiant shimmer.
   - Romantic message subtitle and crown emblem.

4. **Screen 4: 3D Birthday Cake & Wishes**
   - Multi-tiered handcrafted 3D-styled cake with frosting drips, fresh strawberries, and pearls.
   - Interactive candle: click to ignite the glowing flame, click again to blow it out and make a wish!
   - Confetti bursts and magical smoke effects.

5. **Screen 5: Pop the Balloons**
   - Floating colorful balloons with 3D shine and string physics.
   - Pop balloons with authentic pop sound effects and confetti bursts.
   - Unveils 6 personalized secret heartfelt reasons why she is cherished.

6. **Screen 6: Memory Lane**
   - Interactive 3D Polaroid flip-book gallery.
   - Loaded with romantic high-resolution memories (no placeholders!).
   - Tap any photo to flip it over and read handwritten memory notes on the back.
   - Direct button to upload your own photos instantly.

7. **Screen 7: Personal Birthday Letter**
   - Vintage textured parchment paper with wax seal, gold foil accents, and typewriter reveal.
   - In-place *"Edit Letter"* capability to craft your personalized birthday message.

8. **Screen 8: Grand Birthday Celebration**
   - Grand finale: *"HAPPY BIRTHDAY [NAME] ❤️"* with fireworks, confetti showers, and glowing hearts.
   - Interactive buttons to launch more fireworks, shower hearts, or replay the surprise journey.

---

## 🎨 Complete Customization

Click the **⚙️ Settings** icon in the navigation bar at any time to customize:
- **Name & Nickname**: Change the birthday person's name across the entire experience.
- **Photos**: Upload photos directly from your device (saved locally into `localStorage`), edit captions, dates, and notes.
- **Letter**: Customize salutation, paragraphs, and signoff.
- **Balloons**: Personalize the 6 secret messages hidden inside the balloons.
- **Themes**: Switch between *Purple & Burgundy (Signature)*, *Midnight & Gold*, *Rose Gold & Blush*, and *Velvet Ruby & Noir*.
- **Music**: Enjoy synthesized romantic piano lullabies (Web Audio API) or upload your own favorite song (`.mp3`).

## 🚀 Running the Project

```bash
# 1. Install dependencies (already installed)
npm install

# 2. Start the local development server
npm run dev

# 3. Build for production
npm run build
```
